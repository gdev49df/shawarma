# шаурма ашота

сайт шаурмечной «Шаурма Ашота» (Астана). чистые html, css и js, без сборки.

## что внутри

- `index.html` — вся страница: главный экран, меню, конструктор, доставка, контакты, корзина
- `css/style.css` — стили
- `js/data.js` — **все данные, которые нужно менять**: телефон, whatsapp, адрес, часы, условия доставки, меню и цены, вопросы
- `js/app.js` — логика: корзина, фильтры меню, конструктор, оформление заказа в whatsapp, статус «открыто / закрыто»
- `js/vendor/lenis.min.js` — библиотека плавного скролла (MIT)
- `assets/` — фото шаурмы, шрифты (лежат локально), иконка

## перед запуском

сейчас в `js/data.js` стоят примерные данные. заменить на настоящие:

1. `phone`, `whatsapp`, `address`, `landmark`, `instagram`
2. `map` — координаты точки и `pin: true`, чтобы на карте появилась метка
3. `hours` и блок `delivery`
4. `MENU` — блюда, вес и цены
5. фото `assets/img/shawarma.webp` — вырезано из референса, для боевого сайта лучше снять свою шаурму

## запуск

открыть `index.html` в браузере или включить github pages для ветки `main`.
